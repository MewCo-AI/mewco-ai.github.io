让 AI 留在本地，
把数据握在自己手中

在硬件条件充足的情况下，可采用本地部署 AI 的方案，具有低延迟、低风险、低依赖、低漏洞、低限制、低成本的优势。下述插件均为免费开源项目，不仅支持对接 AI 助手，也支持对接第三方软件，或遵循开源协议自由二次开发。

把大模型装进自己的电脑、开发板甚至手机。本地端侧 AI 引擎让语音识别、对话、视觉理解与语音合成都能在本地闭环完成，既降低延迟，也让隐私数据不必离开设备。本页收录经社区验证的开源框架与整合包，持续更新。

版本尾注：C 表示社区版，L 表示 Linux 版，E 表示已停止服务的探索版。标注多个字母代表可对接多个版本；独立运行的工具会单独注明。下载前请确认硬件、系统与版本要求。

为什么选择本地端侧 AI 引擎

云端 API 方便，但长期使用会受网络、费用与隐私约束。只要硬件条件允许，本地部署能让 AI 助手真正成为“自己的助手”。

01
低延迟模型在本机或局域网内推理，省去公网往返，语音对话的响应更即时。
02
低风险对话、图片与文档无需上传云端，敏感数据始终留在自己的设备里。
03
低依赖离线也能运行，不受网络波动、服务限流或接口变更影响。
04
低成本一次部署长期使用，无需按 Token 付费，适合高频日常使用。

本地文本 / 视觉大模型框架

这一类框架负责“思考”：运行语言模型与视觉语言模型，并通过 OpenAI 兼容接口与 AI 助手连接。入门可选整合包，追求性能与可控性则推荐原生 llama.cpp 系框架。

Transformers 整合包 EC

整合 Hugging Face Transformers API 服务器、Qwen3-0.6B 大语言模型与 Python 运行环境。仅支持 CPU，速度较慢，适合入门学习。

免费获取 ↓ 1.42G（度盘）备用夸盘开源地址配置教程
原生 llama.cpp 框架 CL

纯 C/C++ 高性能大模型推理引擎，零外部依赖，支持 GGUF 量化、OpenAI 兼容 API 与交互式 CLI，可运行于 CPU、N 卡、A 卡、Apple Metal 与 Vulkan，从树莓派到服务器全平台部署。

免费获取开源地址配置教程
KoboldCpp 框架 CL

基于 llama.cpp 的单文件可执行文本生成工具，零安装零依赖，内置 KoboldAI Lite Web UI 与多模式创作界面，支持 GGUF 推理、OpenAI 兼容 API 及多前端适配。

免费获取开源地址配置教程
Ollama 框架 ECL

命令行一键下载安装市面主流大模型，基于 llama.cpp，带简易图形界面，支持 CPU、N 卡、A 卡并智能动态分配计算资源。

免费获取开源地址配置教程（新版）配置教程（旧版）
LM Studio 框架 ECL

图形化运行主流 GGUF 大模型，基于 llama.cpp，界面丰富，支持 CPU、N 卡、A 卡与 Vulkan 核显运行。

免费获取开源地址配置教程（新版）配置教程（旧版）
AnythingLLM 知识库 ECL

把任意文档、资源或内容片段转化为大语言模型在聊天中可利用的上下文，支持对接 OpenAI 兼容接口的大模型。

免费获取开源地址配置教程
Dify 聊天助手知识库 ECL

开源 LLM 应用开发平台，支持上传知识库，功能强大。部署难度较高，需要熟悉虚拟机、Linux 系统与 Docker。

开源地址配置教程
RKLLM 框架整合包 L

Rockchip 推出的工具链，可将 LLM 高效部署到其 NPU 平台，支持模型转换与 w4a16、w8a8 量化，实现硬件加速推理。仅适用于 RK3588 / RK3576 芯片。

免费获取 ↓ 2M（度盘）备用夸盘开源地址配置教程

本地语音合成大模型

新版整合包已升级：OmniVoice、Qwen-TTS、VoxCPM 采用原生 audio.cpp 推理引擎 Vulkan 版与 GGUF Q8_0 量化模型，相比旧版 PyTorch CUDA 整合包，平均体积下降约 70%，推理速度提升约 50%，启动速度提升约 90%。AI 助手 Linux 版 v4.3 已对接上述三种新版整合包。
GPT-SoVITS 整合包 ECL

RVC-Boss（花儿不哭）团队 GPT-SoVITS v2ProPlus-250604 官方 API 整合包。支持 CPU 与 N 卡，低显存占用且速度快，适合声音克隆与角色配音。

整合 OmniVoice 0.8B 语音合成大模型 API 服务器与 Python 运行环境，支持声音设计 / 克隆双模式，需要 N 卡运行。新版采用 audio.cpp Vulkan + GGUF Q8_0，体积更小、启动更快。

获取新版 ↓ 1.66G（适配 L，度盘）新版夸盘获取旧版 ↓ 5.08G（适配 E/C，度盘）开源地址配置教程
VoxCPM 整合包 ECL

整合 VoxCPM2-2B 语音合成大模型 API 服务器与 Python 运行环境，支持声音设计 / 克隆双模式，CPU 与 N 卡均可运行。

获取新版 ↓ 2.64G（适配 L，度盘）新版夸盘获取旧版 ↓ 6.92G（适配 E/C，度盘）开源地址配置教程
Index-TTS 整合包 ECL

其他端侧 AI 引擎

以下工具可独立运行，暂不支持直接对接 AI 助手，适合体验端侧多模态能力或进行独立开发。

MNN Chat 手机安装包 Android

采用阿里开源的端侧轻量级推理引擎 MNN，让手机也能畅玩本地多模态大模型，支持 Qwen、DeepSeek、MiniCPM 等模型。

免费获取（Android）开源地址使用教程
Qwen2.5-Omni 整合包 16G

整合 Qwen2.5-Omni-3B 端到端全模态大模型与 Python 运行环境。输入支持视频、图像、语音与文字，输出支持语音与文字，需要至少 16G 显存的 N 卡。
