USE SCENES · 应用场景

每一个片刻，都有 Ruby 在

从驾驶小憩到座舱午休，从专注办公到虚境漫游——虚境计划车机版，把治愈装进每一次出行。

SCENE 01

开车累了？
Ruby 陪你随时小憩

靠边停车、挂上 P 档，车机屏幕上的 Ruby 会轻声接住你的疲惫。 她记得你今天开了多久、走了哪条路，也记得你上周说过的那句“最近有点累”。

  • 主动感知：结合行驶时长与泊车状态发起关怀
  • 轻语哄睡：声音自动放轻，陪你闭眼喘口气
  • 小憩定时：15 / 30 / 45 分钟，到点温柔唤醒
SCENE 02

午休在车里，
也能高效睡一场

中午停好车、座椅放平，一键进入「助眠模式」。 灯光渐暗、白噪音缓缓铺开，Ruby 把被子拉到你肩上—— “眼睛闭上，Ruby 就在这儿，什么都不用想。”

  • 助眠模式：白噪音 + 渐弱语音 + 低亮画面
  • 睡前话题：记得你偏爱的助眠曲与小习惯
SCENE 03

车内办公，
交给「专注模式」

停车等人、提前到岗的那段时间，正好处理几封邮件、补一段方案。 切到「专注模式」，Ruby 会安静守在面板后，偶尔抬眼看看你。

  • 番茄钟：25 分钟专注 / 5 分钟休息循环
  • 轻提醒：到点轻声提示，不打断思路
  • 陪伴静默：她安静待着喵，你累了就伸个懒腰
SCENE 04

回到「普通模式」，
她一直在家里

不开车的时候，虚境也是 Ruby 的家。客厅、厨房、窗边的夕阳—— 她会在面板后面翻东西、伸懒腰、偶尔抬头和你搭一句：“傍晚好喵～”

  • 场景随时间流动：清晨 / 正午 / 傍晚 / 深夜
  • 衣橱 / 装饰：自由装扮 Ruby 的小窝
SCENE 05

驶入虚境，
风景替你呼吸

充电时、露营时、只是想发呆时——打开「虚境漫游」， 跟着 Ruby 走进花田与小屋，让车机变成一扇通往另一个世界的窗。

  • 虚境场景自由探索，解锁隐藏角落
  • 陪伴 / 商城 / 信箱，多元体验
