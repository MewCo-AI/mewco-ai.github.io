开源 AI 助手源码解析

欢迎观看开源 AI 助手配套开发视频教程。14 期内容深入解析各模块代码，从架构、语音、视觉到智能体与虚拟形象，帮助你完成二次开发，创造属于自己的 AI 助手。

本系列以枫云AI助手社区版源码为基础，逐模块拆解一个完整 AI 助手是如何被搭建出来的。建议具备 Python 基础，并按顺序完成第一季的学习后再进入第二季。

开发准备：请提前安装 Python、PyCharm 与 Git，并克隆 GitHub 仓库。视频中的模型与依赖可按需替换，理解模块之间的数据流比记住具体实现更重要。

第一季 · 核心模块

从项目架构与开发环境开始，依次拆解语音识别、大语言模型、语音合成、视觉、声纹、智能体、主动感知与三种虚拟形象模块。

EP.01架构

开源项目概览

全面了解社区版开源项目的核心特性与教程规划，讲解分层架构设计，并完成 Python 环境配置、PyCharm 项目导入与解释器设置等初始化步骤，深入解析主程序的模块化设计。
