枫云AI助手社区版

从第一次启动，
到玩转每一个能力

欢迎观看 AI 助手软件配套使用视频教程。12 期内容覆盖超级智能体对接、自主操控、声纹与语音、角色制作、远程访问、云端 API 与智能家居，跟着视频一步步把助手变成你想要的样子。

更新于 2026-07-26
前往 B 站频道查看开发教程

教程基于枫云AI助手社区版录制，Linux 版的大部分功能与操作方式同理。建议先完成软件安装与基础模型配置，再按兴趣选择章节观看；每期视频都配有可独立实践的完整流程。

观看建议：超级智能体与 IM 机器人章节需要提前准备对应的账号或服务；内网穿透与云端 API 章节涉及第三方平台，请根据自己的网络环境与预算选择。所有视频均可在 B 站官方频道找到。

智能体与远程协作

让助手从“聊天窗口”走向真实世界：对接超级智能体、自主操控电脑、接入即时通讯，把任务交给它执行。

EP.01QwenPaw

对接国产类龙虾 QwenPaw

通过 MQTT 协议将开源 AI 助手对接阿里开源的 QwenPaw。QwenPaw 是 AgentScope 团队打造的本地优先个人 AI 超级助手，支持本地部署、多智能体协作、多 IM 渠道接入、长期记忆与自定义技能扩展。

在 B 站观看
EP.02OpenClaw

对接龙虾 OpenClaw

将开源 AI 助手与开源超级智能体 OpenClaw“小龙虾”对接，以 LobsterAI 为例。OpenClaw 能自主完成文件整理、邮件收发、浏览器操作等跨应用复杂任务，并支持本地运行与持久记忆。

在 B 站观看
EP.03Agent

通用自主操控电脑智能体

学习通用自主操控电脑智能体的使用方法，解析 Lite 版与 Pro 版的区别：Lite 基于 OCR 文字识别适合基础自动化，Pro 基于 VLM 多模态大模型纯视觉感知，宛如人眼读懂屏幕并执行复杂交互。

在 B 站观看
EP.04IM

对接 IM 聊天机器人

让 AI 助手走出本地软件，通过对接 QQ、飞书、钉钉等即时通讯软件实现远程互动，以 QQ 机器人为例演示完整流程。

在 B 站观看

声音、形象与移动端

赋予助手更好听的声音、更生动的形象，并让它跟着你走出家门。

EP.05Zipformer

Zipformer 全域声音感知

介绍基于 Zipformer 架构的音频事件检测技术。由新一代 Kaldi 团队开源，让 AI 助手不仅能听懂人类语言，更能识别环境中的各类声音事件。

在 B 站观看
EP.06TTS

内置 ZipVoice 语音合成

介绍内置 ZipVoice 语音合成功能。ZipVoice 主打轻量化与高速推理，无需独立显卡即可在 CPU 上实现极速零样本声音克隆，兼顾中英双语，适合低配电脑。

在 B 站观看
EP.07声纹

3D-Speaker 声纹识别

用 3D-Speaker 声纹识别技术解决语音交互中的“自识别循环”痛点。通过集成 CAM++ 模型，仅需录制 5 秒语音，就能让 AI 只认你的声音。

在 B 站观看
EP.08VRM

用 VRoid 创造 VRM 角色并转换 MMD

用 VRoid Studio 零门槛捏出专属二次元 3D 角色，一键导出 VRM 后，通过 Vroid2Pmx 转为 MMD 的 pmx 格式，再无缝导入枫云 AI 助手。

在 B 站观看
EP.09远程

手机版使用与内网穿透远程访问

在手机上畅玩枫云 AI 助手：涵盖浏览器直接访问的多种方式（点对点、局域网、远程），并介绍用 Tailscale 内网穿透实现远程访问，随时随地与助手互动。

云端模型与智能家居

低配电脑也能用上大模型，还能让助手接管家里的灯。

EP.10TTS API

自定义云端 TTS-API 语音合成

以 SiliconCloud 云平台为例，演示如何为助手配置自定义云端 TTS 接口，调用 CosyVoice2 等开源语音模型实现高质量文本转语音，并支持通过参考音频进行声音复刻。

EP.11LLM API

自定义任意大语言模型 API

电脑配置跟不上也能体验先进大模型。学习如何接入自定义云端大语言模型 API，例如高性价比的 SiliconCloud，让 AI 体验不再受限于本地硬件。

对接 Home Assistant 智能家居

将 AI 助手与开源智能家居平台 Home Assistant 对接。通过 HA API 与米家集成插件，用一句话控制家中的灯光等智能设备。
