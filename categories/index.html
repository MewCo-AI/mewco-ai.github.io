枫云AI助手社区版是一款高自由度网页 / 桌面二次元 2D / 3D 全能 AI 助手。在 Windows 电脑上运行后，局域网内的电脑、手机、平板甚至车机都能通过浏览器使用，并支持 Live2D 桌宠、通用电脑自主操控与多智能体协作。

枫云AI助手Linux版专为 Linux 极客打造，适配 ARM / X86 开发板与服务器。声纹识别、三大超级智能体、IM 机器人与主机状态监控一应俱全，让 AI 助手真正装进随身硬件。

两个版本均开源免费、无内购，支持云 / 边 / 端三模 AI 引擎。你可以直接下载整合包体验，也可以从 GitHub 获取源码，自由二次开发，创造只属于你的助手。
